# TMDB 高分电影榜单爬虫（学习案例）

使用 requests + lxml + XPath 抓取 TMDB 高分电影榜单，并将电影详情保存为 CSV。

## 运行

pip install requests lxml
python tmdb\_top\_rated\_scraper.py



## 数据

- `data/movie\_list.csv`：TMDB 前100高分电影榜单抓取结果（仅学习用途）


## 说明

仅用于学习交流。TMDB 数据获取推荐使用官方 API（api.themoviedb.org），
直接爬取网站可能违反其服务条款。
仅能爬到英文数据.
